# Habilidade de Revisão de Código

Ao revisar o código, siga estas etapas:

## Checklist de revisão

1. **Correção**: O código faz o que deveria fazer?
2. **Casos de borda**: As condições de erro são tratadas?
3. **Estilo**: O código segue as convenções do projeto?
4. **Desempenho**: Existem ineficiências óbvias?

## Como fornecer feedback

- Seja específico sobre o que precisa ser alterado
- Explique o motivo, não apenas o que deve mudar
- Sugira alternativas sempre que possível
